# 具象化パズル

## 作品概要

プレイヤーが入力した「単語」をゲーム内のオブジェクトとして具象化し、
生成されたオブジェクトを利用してステージを攻略するパズルゲームです。

決められたアイテムを選択するのではなく、
「この状況を解決するには何を具象化すればよいか」を
プレイヤー自身が考えることをゲームの中心にしています。

## 開発情報

- 使用エンジン：Unity
- 使用言語：C#
- 開発期間：約3か月
- 制作形態：個人制作

## 主な実装

### 単語の具象化システム

プレイヤーが入力した単語を判定し、
対応するオブジェクトをゲーム内に生成する仕組みを実装しました。

入力された単語に応じて生成する対象を切り替え、
生成されたオブジェクトをパズル攻略に利用できるようにしています。

### 多言語対応

日本語・英語・中国語・韓国語への対応を目的として、
ゲーム内テキストを切り替えるための `LanguageManager` を実装しました。

言語ごとの表示内容を管理し、
設定した言語に応じてUI上のテキストを変更できる構成にしています。

### ゲーム進行・UI

パズルの進行に必要な処理や、
プレイヤーへの情報表示などのUI処理を実装しました。

※具体的な実装内容については、
`Assets/Scripts` 内のソースコードを掲載しています。

## 工夫した点

本作品では、
「どの単語を入力すれば現在の状況を解決できるか」を考えること自体が
ゲームプレイになるように意識しました。

単純に正解となるアイテムを選択する方式ではなく、
プレイヤーの発想とゲーム内のオブジェクト生成を組み合わせることで、
パズルとしての独自性を持たせています。

また、多言語対応では、
各UIに直接文章を記述するのではなく、
`LanguageManager`を通して表示内容を管理することで、
言語追加や変更を行いやすい構成を目指しました。

## 外部アセットについて

本作品では、Unity Asset Store等で配布されている
第三者制作のアセットを使用しています。

ライセンス上の理由から、
本リポジトリには外部アセットのデータを含めず、
自身で実装したソースコードを中心に掲載しています。

そのため、本リポジトリ単体では
完成したゲームをそのまま実行することはできません。
